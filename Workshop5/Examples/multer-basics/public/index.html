File handling

Upload images with Multer

Two endpoints, two behaviours: one accepts a single photo, the other accepts up to three images at once. Accepted formats are JPEG, PNG and WebP.

Try a single upload Try multiple uploads

Single image

Sends one file to POST /upload-single using the photo field.

No file selected.

Multiple images

Sends up to three files to POST /upload-multiple using the photos field.

No files selected.

What happens on the server?

1. Storage

Files are written to storage/uploads with a random UUID filename.

2. Validation

MIME type and size are checked before the file is accepted.

3. Response

The API returns JSON describing the uploaded files or a helpful error.
